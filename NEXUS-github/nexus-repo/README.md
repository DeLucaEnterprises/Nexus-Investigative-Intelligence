## What is NEXUS?

NEXUS is a self-contained, browser-based investigation intelligence platform built for missing persons cases, law enforcement, journalists, researchers, and nonprofit investigators. It runs entirely in your browser — no installation, no server, no account required.

**Core capabilities:**
- **Visual relationship mapping** — 32 node types across people, places, communications, assets, and intelligence categories connected by a live physics graph
- **Case management** — create, organize, and switch between multiple investigations
- **Document analysis** — upload PDFs or paste text; NEXUS extracts entities, relationships, and timeline events with confidence scoring
- **Subject profiles** — extract structured intelligence from background reports and map it directly to the graph
- **Intel Agent** — AI-powered web search agent with case context, quick-action prompts, and streaming responses
- **Timeline** — chronological event tracking with drag-to-reorder, inline editing, and auto-population from graph nodes
- **Case reports** — full formatted investigation reports with print/export
- **Import / Export** — CSV, JSON, and native `.nxs` format

## Quick Start

1. **Download** `nexus-investigation.html`
2. **Open** it in any modern browser (Chrome, Edge, Firefox, Safari)
3. That's it — no install, no account, no internet required for core features

> The AI Intel Agent requires an [Anthropic API key](https://console.anthropic.com). Your key is stored only in your browser's local storage and sent directly to Anthropic — never to any third party.
