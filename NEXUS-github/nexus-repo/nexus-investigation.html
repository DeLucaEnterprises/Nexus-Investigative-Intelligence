Platform
NEXUS is a self-contained, browser-based investigation intelligence platform. All case data is stored locally in your browser using IndexedDB — nothing is uploaded to any server. The AI Analyst feature optionally connects to Anthropic's API using your own key.
Data Privacy
NEXUS does not collect, transmit, or store any user data externally. Your cases, notes, and investigation data never leave your device except when you explicitly use the AI Analyst (which sends case context to Anthropic's API) or when you export a file yourself.
